## Preparation

A text editor provides the means necessary to simply edit text. However it does not provide
anything further than that. An IDE, however, provides additional functionality. For example,
IDEs typically have built-in compilers and debuggers. Additionally, they provide syntax
highlighting and more advanced editing capabilities than a standard text editor.

In general, IDEs are more suited for programming than a standard text editor.


A for loop is composed of four main parts: a declaration, condition, step and code. For example:
```java
for(int i = 0; i < 20; i++) {
    System.out.println(i);
}
```
iterates through every integer `i` between 0 (inclusive) and 20 (exclusive), and prints it out.


There is one difference between `System.out.print` and `System.out.println`. `print` will output
*exactly* what is given as input, and no more. However, `println` will output an extra newline
character. For example:
```
System.out.print("Hello");
System.out.print("World");

--- OUTPUT
HelloWorld
```
```
System.out.println("Hello");
System.out.println("World");

--- OUTPUT
Hello
World
```
