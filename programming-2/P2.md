### Prep Work
1. A class defines the structures and methods for any object that uses it. An object is an *instance* of a class, using its methods and attributes.
2. A constructor provides all the code necessary to create an object of a specific class. This eliminates the need for repeated code when instantiating a class. Additionally, they can also be overloaded to isntantiate a class differently based on the arguments given to them. However, if you were assigning the values directly, there is a much higher margin for error that may result in an object being incorrectly instantiated.
3. As `isStaff` is a private member of `SmartCard`, trying to directly set its value outside of the class would cause an error and prevent the program from compiling. However, as `setStaf()` is a public method, it can be used outside of the class to change the value of `isStaff` without issue.
