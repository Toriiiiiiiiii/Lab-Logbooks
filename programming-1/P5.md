### Sec 2.1
* The `except` statement catches an exception raised inside of a `try` statement.
* The `else` statement is run if no exception is raised inside of a `try` statement.
* The `finally` statement is used for cleanup in the event of an exception being raised.

### Sec 2.2
```py
from math import sqrt

def test_sqrt() -> None:
    assert sqrt(0) == 0, "sqrt(0) != 0"
    assert sqrt(4) == 2, "sqrt(4) != 2"
    assert sqrt(16) == 4, "sqrt(16) != 4"

    try:
        sqrt(-10)
    except ValueError:
        assert True
    else:
        assert False, "ValueError not raised by sqrt() with negative value."

    try:
        sqrt("4")
    except TypeError:
        assert True
    else:
        assert False, "TypeError not raised by sqrt() with non-numerical value."
```

def divide_numbers(numerator, divisor) -> float:
    if divisor == 0:
        raise ValueError("Cannot divide by zero. Please provide a non-zero divisor.")

    return numerator / divisor

### Sec 3.1.2
```
import math

def find_square_root(x):
    if type(x) != int and type(x) != float:
        raise ValueError("Input is not a number.")
        
    if x < 0:
        raise ValueError("Cannot compute square root of negative numbers.")

    return math.sqrt(x)
```
