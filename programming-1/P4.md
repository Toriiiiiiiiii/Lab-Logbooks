* Python code:
```py
def find_common(fileA: str, fileB: str) -> list[str]:
    fileA_lines: list[str] = []
    common_lines: list[str] = []

    with open(fileA, "r") as f:
        fileA_lines = f.readlines()

    with open(fileB, "r") as f:
        for line in f.readlines():
            if line in fileA_lines:
                fileA_lines.remove(line)
                common_lines.append(line)

    return common_lines
```
