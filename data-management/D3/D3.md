# Lab D3 - 19/11/2025
* Selecting all planets in the alpha quadrant:
```sql
SELECT * 
FROM planets 
WHERE quadrant='Alpha';
```

* Selecting resource name and amount for all resourcees on planet with id '1'
```sql
SELECT resources.name, planets_resources.amount 
FROM planets JOIN planets_resources JOIN resources 
WHERE planets.id = 1 
    AND planets.id = planets_resources.planet_id 
    AND resources.id = planets_resources.resource_id;
```

* Count of all planets in alpha quadrant
```sql
SELECT COUNT(*) 
FROM planets 
WHERE quadrant = 'Alpha';
```
* Result: `53`

* Sum of all iron
```sql
SELECT SUM(planets_resources.amount)
FROM planets_resources JOIN resources
WHERE planets_resources.resource_id = resources.id
    AND resources.name = 'Iron';
```
* Result: 821517

* Sum of all resources in Alpha quadrant
```sql
SELECT resources.name, SUM(planets_resources.amount) 
FROM resources JOIN planets_resources JOIN planets 
WHERE resources.id = planets_resources.resource_id 
    AND planets_resources.planet_id = planets.id 
    AND planets.quadrant = 'Alpha' 
GROUP BY resources.name;
```

```
| Antimony     | 84337                         |

```
